# はじめに

Pluginsプレビューに対応した **Interceptor 1.1.0以降**が必要です。プラグインは通信情報を受け取って処理するスクリプトです。現在のプレビューでは用意されたテストデータでサンプルを実行し、結果を確認できます。実際の通信を送受信する機能ではありません。

## リポジトリを追加する

リポジトリを追加すると、配布されているプラグインの一覧が表示されます。リポジトリを追加しただけではスクリプトは実行されません。一覧からスクリプトを選び、無効状態で読み込んでテストします。

**設定 → Plugins → ＋ → リポジトリを追加**を開き、次のURLを入力します。

```text
%%REPOSITORY_URL%%
```

追加前のプレビューではリポジトリ名とスクリプト数を確認できます。署名付きの場合は、署名鍵の指紋も表示されます。ソースとマニフェストは、リポジトリを追加してから各スクリプトの詳細で確認します。

## 信頼の確認

指紋は配布元の署名鍵を識別する64文字の値です。次の手順で、Interceptorに表示された鍵が、信頼している配布元のものかを確認します。

このリポジトリの公開鍵（Ed25519）のSHA-256指紋:

```text
%%FINGERPRINT%%
```

1. Interceptorのリポジトリ追加プレビューに表示された指紋を確認します。
2. 以前から信頼している配布元の連絡先など、このサイト・フィードとは別の経路で比較用の指紋を入手します。
3. 2つの値が**64文字すべて一致するか**確認します。比較用の指紋を入手できない場合や、値が一致しない場合、有効な指紋が表示されない場合は、その鍵が信頼している配布元のものだと確認できません。信頼せず、追加を中止してください。

このページの値だけでは確認は完了しません。このサイトとフィードは同じGitHub管理権限の下にあり、独立した確認経路ではありません。このページでは別経路の確認先を案内していません。

- **パッケージのSHA-256**は一覧とパッケージの不一致を検知するものです。署名のない配信元では両方を差し替えられます。
- **公開鍵の指紋**は署名鍵を識別するSHA-256値です。初めて見る鍵の署名が正しくても、公開者の本人確認にはなりません。
- **Ed25519署名**は、一覧とそこに記載されたパッケージのハッシュが、その鍵で署名されてから変わっていないことを確かめます。

## 読み込んでテストする

このテストは、用意された入力からどんな結果が返るかを確かめる操作です。外部への送信は行いません。

1. 一覧からパッケージを選び、ソースを確認します。
2. **Import Disabled**（無効状態で読み込む）を選びます。
3. 読み込んだスクリプトを開き、フックを選んで**Run Synthetic Test**（テストデータで実行）を選びます。

| サンプル | フック | 既定入力で表示されるJSONペイロード |
|---|---|---|
| Request summary | Request | `{"summary":"GET example.com/synthetic"}` |
| Server error filter | Response | `{"host":"example.com","status":503}` |

アクションを返さないケースを試すには、レスポンスのテスト入力でステータスを `200` に変更します。Request専用スクリプトには `onResponse` がなく、Response専用スクリプトには `onRequest` がありません。各スクリプトに対応するフックを選んでください。

## プレビューの範囲

v1の**合成プレビュー**では指定したテストデータでスクリプトを同期実行し、返されたWebhookへの送信要求（intent）を表示します。

- 返せる送信要求（intent）は最大2件です。
- Webhookへの**送信（delivery）はしません**。
- 実際にキャプチャした通信を対象とした処理は行いません。
- バックグラウンドでは実行しません。
- 読み込み時は無効状態で保存します。サンプルは本文・ヘッダー・クエリ値を要求しません。

結果が表の内容と一致すれば、サンプルがテストデータに対して想定どおりの結果を返したことを確認できました。現在のプレビューで試せるのはここまでです。実際の通信で自動実行する操作はありません。別のサンプルは[サンプル一覧](examples.md)で確認できます。自分で作りたい場合は[TypeScriptの書き方](authoring.md)へ進んでください。
