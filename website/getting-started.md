# はじめに

Pluginsプレビューに対応した **Interceptor 1.1.0以降**が必要です。プラグインは、通信情報を入力にして処理するスクリプトです。現在のプレビューでは、用意されたテストデータでサンプルを実行し、結果を確認できます。実際の通信を送受信する機能ではありません。

## リポジトリを追加する

リポジトリを追加すると、配布されているプラグインの一覧が表示されます。追加だけでスクリプトが実行されることはありません。一覧から選んだものを無効状態で読み込み、テストします。

**設定 → Plugins → ＋ → リポジトリを追加**を開き、次のURLを入力します。

```text
%%REPOSITORY_URL%%
```

追加前のプレビューでは、リポジトリ名とスクリプト数を確認できます。署名付きの場合は、署名鍵の指紋も表示されます。ソースとマニフェストは、リポジトリを追加してから各スクリプトの詳細で確認します。

## 信頼の確認

指紋は、配布元の署名鍵を識別する64文字の値です。信頼できる別の経路で入手した指紋と**全体が一致するか**確認してください。一致しない場合や、下に有効な指紋が表示されない場合は、配布元を確認できないため信頼しないでください。

このリポジトリの公開鍵（Ed25519）のSHA-256指紋:

```text
%%FINGERPRINT%%
```

- **パッケージのSHA-256**は、一覧とパッケージの不一致を検知するものです。署名のない配信元では両方を差し替えられます。
- **公開鍵の指紋**は署名鍵を識別するSHA-256値です。初めて見る鍵の署名が正しくても、公開者の本人確認にはなりません。
- **Ed25519署名**は、一覧とそこに記載されたパッケージのハッシュが、その鍵で署名されてから変わっていないことを確かめます。
- このサイトとフィードは同じGitHub管理権限の下にあるため、このページだけでは独立した確認経路になりません。信頼できる別の経路で**指紋全体**を照合してからpinしてください。

## 読み込んでテストする

このテストは、用意された入力からどんな結果が返るかを確かめる操作です。外部への送信は行いません。

1. 一覧からパッケージを選び、ソースを確認します。
2. **Import Disabled**（無効状態で読み込む）を選びます。
3. 読み込んだスクリプトを開き、フックを選んで**Run Synthetic Test**（テストデータで実行）を選びます。

| サンプル | フック | 既定入力で表示されるJSONペイロード |
|---|---|---|
| Request summary | Request | `{"summary":"GET example.com/synthetic"}` |
| Server error filter | Response | `{"host":"example.com","status":503}` |

アクションを返さないケースは、レスポンスのテスト入力のステータスを `200` に変えて確認します。Request専用のスクリプトに `onResponse` はなく、その逆も同様なので、スクリプトに合うフックを選んでください。

## プレビューの範囲

これは同期的なv1の**合成プレビュー**です。明示的に渡した入力で実行し、返されたWebhook intentを表示します。

- 返せるintentは最大2件です。
- Webhookへの**送信（delivery）はしません**。
- 実際にキャプチャした通信へは接続しません。
- バックグラウンドでは実行しません。
- 読み込み時は無効状態で保存します。サンプルは本文・ヘッダー・クエリ値を要求しません。

結果が表の内容と一致すれば、サンプルの読み込みとテストは完了です。別のサンプルは[サンプル一覧](examples.md)で確認できます。自分で作りたい場合は[TypeScriptの書き方](authoring.md)へ進んでください。
